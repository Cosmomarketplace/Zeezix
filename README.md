# Zeezix — Kids Games

Six single-file HTML5 games for the Zeezix YouTube channel (ages 4–10), wired for YouTube Playables
(SDK bridge with localStorage fallback, pause/resume, audio setting, saveData/loadData, sendScore).

- `index.html` — launcher
- `game1_rainbow_runner.html` — lane-switch runner (Zeezix + friends, Land / Reef themes)
- `game2_magic_coloring_book.html` — tap-to-fill coloring, 9 scenes
- `game3_color_dash.html` — run + paint hybrid, 8 pictures
- `game4_bubble_pop_abc.html` — pop the letter bubbles, A–Z with number rounds
- `game5_reef_pairs.html` — memory match with the reef friends
- `game6_zeezix_swim.html` — hold-to-swim through coral, collect stars

No external calls except the Playables SDK script. No ads, no data collection, Made for Kids.
Live copy for the open web: https://zeezix.netlify.app (upload the same files there).
